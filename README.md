# Digital Notice Board

A simple, responsive digital notice board system for educational institutions built using pure HTML, CSS, and JavaScript.

# How to Run

1. Open the project folder.
2. Double-click index.html to run it directly in any browser.
(Optional: Open using VS Code Live Server extension).

# Admin Credentials

- Login Page: admin-login.html
- Username: admin
- Password: admin123

# File Structure

- index.html - Home page
- notices.html - Public notice board (Search & Filter)
- admin-login.html - Admin login
- admin-dashboard.html - Notice management panel (Post & Delete)
- about.html - System information
- style.css - Main stylesheet
- script.js - Main logic & local storage handling

# Live Demo Deployment (GitHub Pages)

1. Push all files to a public GitHub repository named digital-notice-board.
2. Open your repository on GitHub and go to Settings > Pages.
3. Under Branch, select main and / (root), then click Save.
